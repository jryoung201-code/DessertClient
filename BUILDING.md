# Building DonutSMP Client

GitHub Actions automatically attempts to compile the mod on pushes to `main`. Open the Actions tab to view the build and download the `DonutSMP-Client-1.21.11` artifact when the workflow succeeds.

Version v0.3.5 adds the client-side Freecam module and retains Spawner ESP. The build workflow uploads the compiled JAR as an artifact and publishes it as a GitHub release.
